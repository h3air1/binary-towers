# Binary Towers CRM

Full-stack CRM built during a hackathon.

## Stack
- **Backend:** Node.js + Express, PostgreSQL, JWT authentication, bcrypt password hashing, rate-limiting, Helmet
- **Frontend:** React + Vite (TypeScript)
- **Infra:** Docker Compose
