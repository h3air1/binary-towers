# Клиника · CRM (frontend)

Фронтенд CRM-системы частной клиники на **React + Vite**. Подключается к вашему
Node/Express + PostgreSQL бэкенду (эндпоинты `/api/...`).

## Запуск

```bash
npm install
npm run dev
```

Откроется на **http://localhost:3000** (порт выбран, чтобы совпасть с `CORS_ORIGIN`
бэкенда по умолчанию).

> Бэкенд должен быть запущен отдельно на порту **5000**.

## Адрес бэкенда

По умолчанию — `http://localhost:5000`. Изменить можно двумя способами:

1. Создать файл `.env` (скопировать из `.env.example`):
   ```
   VITE_API_URL=http://localhost:5000
   ```
2. Или прямо на экране входа → «Настройки подключения к API».

## Структура проекта

```
src/
  api/client.js            — все запросы к REST API в одном месте
  lib/
    format.js              — форматтеры (даты, деньги, статусы) и константы
    storage.js             — безопасный localStorage + адрес API по умолчанию
  context/ToastContext.jsx — глобальные уведомления (useToast)
  components/
    icons.jsx              — SVG-иконки
    ui.jsx                 — Modal, Field, Confirm, StatusPill и др.
    forms/                 — DoctorForm, PatientForm, ApptForm
  pages/                   — Auth, Dashboard, Doctors, Patients, Appointments
  layout/Workspace.jsx     — сайдбар, шапка, переключение разделов
  App.jsx                  — управление сессией (вход / выход)
  main.jsx                 — точка входа
  index.css                — все стили
```

## Возможности

- Авторизация (JWT) — вход и регистрация сотрудника с ролью.
- Дашборд со сводной статистикой и визитами на сегодня.
- Врачи, Пациенты — таблицы с поиском, добавлением, редактированием, удалением.
- Визиты — фильтр по статусу, смена статуса в строке, планирование приёма.
- Индикатор связи с API, тосты, скелетоны загрузки, адаптив до мобильных.

## Первый вход

В системе пока нет пользователей — на экране входа нажмите «Создать» и
зарегистрируйте первого сотрудника, затем войдите.
